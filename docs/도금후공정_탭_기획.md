# 도금 다음 공정 세 탭 기획 — PR 스트립 · 시드 식각 · 리플로우

> 전해도금 탭과 같은 '도면 극장' 화면(공용 엔진 `src/theatre.js`)으로, 도금 다음의 세 공정을 각 9장으로 설명합니다.
> 수치는 교과서 · 공개 문헌 수준의 예시이고 사내 공정 조건은 넣지 않습니다. 계산 위젯은 경향을 보여 주는 **개념 모델**입니다.
> **개정(범프 층 구조)** — 앞면(FS) 범프 도금 구조를 현업 기준에 맞춰 두 가지로 나눴습니다: **코어 다이 Ni / SnAg**(예시 Ni 5 + SnAg 12 µm), **베이스 다이 Cu / Ni / Cu / SnAg**(예시 Cu 기둥 12 + Ni 3 + 상부 Cu 3 + SnAg 12 µm = 30 µm). 세 탭의 그림은 베이스 다이 범프를 기준으로 그리고, 코어 다이에서 달라지는 점(스트립 · 식각에서 드러나는 금속, 리플로우의 젖음 면과 IMC)을 따로 짚습니다. 아래 기획 본문의 'Cu 15 + Ni 3 + SnAg 12 µm'와 'Cu → Ni → SnAg'는 개정 전 기록입니다.
> 장면 · 문구 · 위젯의 원본은 `src/strip/` · `src/etch/` · `src/reflow/` 의 장 파일(장마다 한 파일)이고, 이 문서는 기획과 검토 기록입니다. 장 파일과 이 문서가 다르면 장 파일이 최신입니다.

1. **기획(rev.1)** — 탭마다 기획 담당이 장 구성 · 단계 · 장면 · 위젯 모델 · 노트 · 사실 표를 공개 자료로 확인하며 썼습니다.

- (과학 · 열린 질문 1) '진한 HF(약 11 %)' — 검색으로 확인한 특허 요약은 '묽은 HF'로 적고 있어 농도를 확인 못 함 → 농도 없이 'HF로 Ti 장벽층을 지운 공개 특허 사례'로.
- (현장 · 07) 예시 '필요한 과식각 약 51 % → 20 %대' — 다시 계산하면 속도 맵이 두께 맵을 상쇄해도 로딩(밀도 20 %)이 남아 **51 → 44 %**. 20 %대(21 → 15 %)는 밀도 0 일 때만.
- (현장 · 05 면적비) '전면 Ti가 남았을 때 R ≈ 0.2' — 받는 쪽은 범프 윗면만이 아니라 옆면(π·D·높이)도 포함해야 함 → 한 칸 기하로 **R ≈ 1.1**. 결론(남아 있는 동안 가속이 작다)은 같음.
- (교육 · 링크) 08장 single · batch 단계를 'PR 스트립 05장' 한 줄로 줄이기 — 08장 위젯 · 장면 · 발표 모드 흐름에 두 단계가 필요하고 탭 안에서 스스로 읽혀야 하므로 단계는 두고, 노트 · 아래 패널에 링크와 '식각에만 있는 것'(숨은 식각, 단계 사이 헹굼 · 회수 경로, 과산화수소 분해, 첫 장 효과)을 더함.

**장면 공통 치수 (그림 예시 · 장마다 같은 비율로)**

- 범프 예시: 지름 D 25 µm(a = 12.5 µm), 피치 55 µm, Cu 기둥 15 µm, Ni 3 µm, SnAg 도금 높이 H_c 12 µm(원기둥). 시드(Ti + Cu)는 시드 식각 뒤라 기둥 아래에만 있고, 가장자리가 0.5 µm 안쪽으로 깎인(언더컷) 모습(그림 과장, 툴팁 "실제 수백 nm — 그림은 과장").
- 배율: 확대 12 px/µm(01 · 06), 14 px/µm(07 왼쪽 큰 범프는 12), 8 px/µm(04 두 범프), 계면 확대 60 px/µm(05), 산화막 6 px/nm(03, "크게 과장").
- 돔(구형 모자) 그리기 — 각 장 파일 안에 같은 도우미를 둔다:

```js
// 구형 모자: 가운데 cx, 바닥선 y0, 바닥 반폭 a(px), 높이 h(px). h > a 이면 반구보다 큰 호(large-arc 1)
const cap = (cx, y0, a, h) => { const R = (a * a + h * h) / (2 * h); return `M${cx - a},${y0} A${R.toFixed(1)},${R.toFixed(1)} 0 ${h > a ? 1 : 0} 1 ${cx + a},${y0} Z`; };
// 부피 V(µm³)와 바닥 반지름 a(µm) → 돔 높이 h(µm): πh(3a² + h²)/6 = V (이분법)
function capH(a, V){ let lo = 0, hi = 6 * a + 60; for (let k = 0; k < 60; k++){ const m = (lo + hi) / 2; if (Math.PI * m * (3 * a * a + m * m) / 6 < V) lo = m; else hi = m; } return (lo + hi) / 2; }
// 접촉각 θ(rad)로 바닥 반지름 r을 정하는 모자(덜 덮일 때): V = πr³(2 − 3cosθ + cos³θ)/(3 sin³θ)
const capR = (V, th) => Math.cbrt(3 * V * Math.pow(Math.sin(th), 3) / (Math.PI * (2 - 3 * Math.cos(th) + Math.pow(Math.cos(th), 3))));
```

- 예: a 12.5, V 5,890 → h 15.72 µm, 겉보기 각 2·atan(h/a) = 103°, 구 반지름 (a² + h²)/(2h) = 12.83 µm(바닥보다 0.33 µm 불룩).
- 원인 꼬리표 색(09장과 노트에서): 장비 빨강 · 분위기 하늘 · 조건 청록 · 앞 보라 · 뒤 주황 — 전해도금 12장의 `p12-tg` 색과 같게, 클래스는 `rf09-tg.eq/atm/cond/up/dn`.
- 장면 글자: 패널 폭에 맞춰 `K.wrap(글, em)` (t-sub 21 px → 1em ≈ 21 px). 확대 단계 글은 `pl-zt`(13 px).
